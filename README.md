# GenMcScript

A simple tool for generating Minecraft assets based on vanilla Minecraft models.

GenMcScript uses a **single, simple command** to generate ready-to-use:
- models for **items** and **blocks**
- blockstates
- recipes
- loot tables

Usage instructions can be found here -> [Example Usage](./doc/generate.md)

Settings instructions can be found here -> [Settings Usage](./doc/settings.md)

## Purpose
This tool is designed to **quickly generate asset and data files for Minecraft mods**, making resource creation faster and easier.
